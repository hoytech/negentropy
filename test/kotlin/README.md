# Negentropy Kotlin Implementation

Available as a Maven Central package, repo available [here](https://github.com/vitorpamplona/kmp-negentropy).

## Running tests

* Install a JDK and Kotlin, instructions [here](https://kotlinlang.org/docs/command-line.html).
* Run `make` to download the published jar (`kmp-negentropy-jvm-<version>.jar`) from Maven Central.
* Run tests, e.g. `perl test.pl cpp,kotlin` from the `test` directory.
